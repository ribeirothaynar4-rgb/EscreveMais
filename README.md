# Escreve+ — Modo Gratuito Protegido

Assistente pessoal de escrita para Android. Mostra uma bolha flutuante por cima de outros aplicativos, lê somente o campo de texto ativo quando você toca na bolha e oferece versões corrigidas/melhoradas por IA (Gemini).

## Baixar o APK

**[Baixar EscreveMais.apk](https://github.com/ribeirothaynar4-rgb/EscreveMais/releases/latest/download/EscreveMais.apk)**

Página da versão: [Releases](https://github.com/ribeirothaynar4-rgb/EscreveMais/releases/latest)

No Android, o sistema pode pedir permissão para instalar apps desta fonte. Isso é normal para um APK fora da Play Store.

Se aparecer **“O app não foi instalado”**, apague o arquivo antigo `EscreveMais.apk` da pasta Downloads e baixe de novo por este link.

## Como usar depois de instalar

1. Crie uma chave da Gemini API em um projeto que permaneça no **Free Tier** e **sem faturamento pago**.
2. Abra **Escreve+** (ícone roxo com estrela).
3. Cole a chave da Gemini API e salve.
4. Toque em **Ativar assistente** e ligue **Escreve+ — Assistente de escrita** em Acessibilidade.
5. Abra WhatsApp (ou outro app), toque no campo de mensagem e digite.
6. Toque na bolha `✦`.
7. Escolha Corrigir / Melhorar / Natural / Profissional / Curta.
8. Toque em **Usar esta**.

## Modo gratuito protegido

- Modelo fixo no código: `gemini-3.5-flash-lite` (não dá para trocar no app).
- Sem Google Search, Maps ou grounding.
- Até 4.000 caracteres de entrada e 300 tokens de saída.
- Limite local: 50 usos/dia e 500/mês.
- Em erro de cota (`429`) ou pedido de faturamento, o app **para**.

O Escreve+ não ativa faturamento por conta própria. Use uma chave de um projeto Google que permaneça no Free Tier.
